# Wedge Personas

## 1. Head of Platform
Pain:
- agents can change infra and code faster than the approval model evolved

Buy because:
- wants explicit authority boundaries and proof records for risky automation

## 2. Security Engineering Lead
Pain:
- logs do not answer what the agent was allowed to do or why

Buy because:
- wants deny/escalate controls and incident-ready chain of custody

## 3. CTO at AI-Native Startup
Pain:
- agent speed is valuable but uncontrolled automation creates existential blast radius

Buy because:
- wants agent leverage without blind trust
