# Positioning

MissionLedger is not an observability dashboard for AI agents.

It is a governed execution substrate with:
- explicit mission boundaries
- deterministic policy decisions
- budget enforcement
- human approval loops
- replayable proof events
- degraded-state truth instead of fake green dashboards

Category statement:
- Governed agent execution substrate

Wedge statement:
- The trust layer for coding and operations agents used by platform and security teams.

Anti-vapor rules:
- Do not say “secure AI” unless a concrete enforcement path exists.
- Do not say “agent governance” when the system only logs after the fact.
- Do not say “compliant” when the product only exports evidence.
